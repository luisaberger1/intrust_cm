The PROCESS macro for R (process.R) is required to run scripts:
  h1b_moderation_diagnoses.Rmd
  h1b_moderation_diagnoses_supp.Rmd
  h2a_mediation_white_matter_pcl.Rmd
  h2a_mediation_white_matter_pcl_supp.Rmd
  h2b_mediation_white_matter_rpq.Rmd
  h2b_mediation_white_matter_rpq_supp.Rmd

Download process.R free of charge from:
  https://processmacro.org/download.html

Place it in this folder (code/utils/process.R) before running the scripts above.

Reference:
  Hayes, A. F. (2022). Introduction to mediation, moderation, and conditional
  process analysis (3rd ed.). Guilford Press.
